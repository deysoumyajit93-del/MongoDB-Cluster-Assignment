# MongoDB Atlas – Data Generation, Monitoring & Capacity

## Files
- `config.py` – shared configuration (M0 capacity = 512 MB, 20 variables, etc.)
- `generate_and_push.py` – generates a document with 20 variables per loop iteration and pushes to Atlas.
- `run_20_environments.py` – runs the generator in 20 separate processes (environments).
- `pull_and_monitor.py` – pulls documents from Atlas and records CPU, memory, network usage + per-document size.
- `m0_capacity.py` – math for total documents storable in an M0 cluster.
- `progress_bar_atlas.py` – real-time progress bar of M0 storage occupancy (0–100%).

## Setup
1. Create a MongoDB Atlas M0 cluster and a database user.
2. Allow your IP in Network Access.
3. Set the connection string:
   - PowerShell: `$env:MONGO_URI="mongodb+srv://user:pass@cluster.mongodb.net/?retryWrites=true&w=majority"`
4. Install deps: `pip install -r requirements.txt`

## Usage
Run 20 environments:
```
python run_20_environments.py
```
Observe the Atlas **Metrics / Operational Log** (Database Access / cluster metrics) while it runs.

Pull + monitor machine parameters:
```
python pull_and_monitor.py
```

M0 capacity calculation:
```
python m0_capacity.py
```

Real-time storage progress bar:
```
python progress_bar_atlas.py
```

## Notes
- M0 free tier storage is 512 MB. Total documents ≈ 512 MB / (avg document size × overhead factor).
- Network counters are system-wide (psutil). CPU/memory are sampled every 0.5 s during the pull.

## Additional tools
- `aggregate_report.py` – per-environment aggregation (count, avg/min/max of variables) + CSV.
- `alert_check.py` – fail (exit code 2) if M0 occupancy exceeds threshold (default 80%).
- `plot_metrics.py` – plots CPU/memory/network time series from `metrics_timeseries.csv`.
- `metrics_timeseries.csv` – generated by `pull_and_monitor.py` for plotting/analysis.

## Observed run (Atlas, 20 environments × 500 docs)
- Total inserted: 10,000 documents (~495–512 bytes each, BSON).
- Pull: 10,000 docs in 9.38 s (~1,066 docs/s); avg doc size 512 bytes.
- Machine while pulling: CPU avg 26.5% (max 42.1%), memory avg 74.0% (max 75.3%), net recv 5.22 MB, sent 0.15 MB.
- Storage: 2.48 MB used → 0.48% of M0.
- Capacity math: 512 MB / 512 B ≈ 1,048,576 raw; ≈ 838,860 with 25% overhead.
